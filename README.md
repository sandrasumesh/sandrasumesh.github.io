# sandrasumesh.github.io

Personal portfolio site for Sandra Sumesh. It's a single static `index.html` with no build step, hosted on GitHub Pages.

Live at **https://sandrasumesh.github.io**

## Editing

Open `index.html` in any text editor, change the text, commit, and push. GitHub Pages redeploys within a minute or two.

- Projects are in the `<section id="projects">` block. Copy an `<article class="proj">` to add one.
- `spotify-streams/` holds the CMSC320 data science project (notebook plus its HTML export), live at https://sandrasumesh.github.io/spotify-streams/
- Colors and fonts are the CSS variables at the top of the `<style>` block.
