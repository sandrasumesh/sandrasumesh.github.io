LedgerLens

AI analyst for payment reconciliation

A rule-based engine matches a company ledger against the bank feed and flags seven kinds of discrepancy, including duplicate payments, fee errors and short payments. A Claude-powered agent then answers questions like "Why is this deposit short?" using read-only SQL tools, and cites every number it quotes.

  • 100% precision and recall on 19 known problems planted in a 262-row dataset, across five random seeds
  • Money math stays deterministic; the LLM only explains it
  • 24 tests with GitHub Actions CI

ScanBrief

Security scans → plain-English client reports

Parses Nmap and OWASP ZAP output into a ranked security report for healthcare clinics. Claude writes structured JSON that is validated against the original scan before it reaches the client, with an automatic retry if a draft cites a finding that doesn't exist.

  • Every finding maps to a HIPAA Security Rule safeguard
  • Each priority score comes with its reasons
  • 15 tests with GitHub Actions CI
